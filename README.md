## 🛠️ Stack tecnológico
- **Backend:** Java 21, Spring Boot, Spring Security, JPA/Hibernate
- **Base de datos:** PostgreSQL (NeonDB)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Autenticación:** JWT
- **Pagos:** MercadoPago (sandbox)
- **Gestión:** Trello | Figma | GitHub
